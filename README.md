# 前線防衛タワーディフェンス

近代戦をテーマにした固定ルート型タワーディフェンスゲームです。ブラウザだけで遊べます。

## 遊ぶ

https://koron950705.github.io/Tower-Defense-Game/

## 内容

- タワー5種(機関銃・対戦車砲・迫撃砲・狙撃兵・ロケット砲)
- 敵5種(歩兵・重歩兵・装甲車・軽戦車・重戦車)
- ステージ3種、各ステージでウェーブを撃退してクリアを目指す
- グラフィック・効果音はすべてCanvas / Web Audio APIで生成(外部素材不使用)

## ローカルで動かす

ES modulesを使っているため `file://` では動作しません。Node.jsで同梱のサーバーを起動してください。

```
node serve.js
```

起動後、表示されるURL(例: http://localhost:8080)にブラウザでアクセスします。
